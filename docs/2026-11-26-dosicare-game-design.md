# DosiCare 게임 설계 (v1)

2026-11-26 사용자 승인.

## 한 줄
업계 사람(방사선종양학과 동료)이 폰으로 하는 슈팅 게임. 리니악 비행선으로 암에 처방선량을
채우되, 정상 장기 선량 한계를 넘기면 진다.

## 결정 사항
| 항목 | 결정 |
|---|---|
| 장르 | 비행 슈팅 + 실제 치료 규칙 섞기 |
| 대상 | 동료·업계 사람. 용어 설명 최소, 업계 농담 |
| 기기 | 핸드폰 세로 화면 위주. PC 키보드/마우스도 됨 |
| 형식 | `index.html` 1개, 외부 그림 파일 없음 (Canvas로 그림) |

## 화면
- 배경: 치료계획(TPS) 화면처럼 흑백 CT 단면 + 색깔 윤곽선. 방사선학 표기(환자 우측 = 화면 왼쪽, 전방 = 위).
- 비행선은 몸 아래(후방)에만 있음. 빔은 위로 나감 → 빔 경로 앞쪽 장기는 입사 선량, 뒤쪽 장기는 출구 선량.
- 조작: 손가락으로 끌면 비행선이 따라 움직임(상대 이동). 빔은 자동 발사. 짧게 톡 = 양성자 목표 지정.

## 규칙
- 암 체력 = 처방선량(Gy). 다 채우면 소멸. 주 종양을 모두 없애면 스테이지 클리어.
- 정상 장기(OAR)마다 선량 게이지와 한계. 한계 초과 = "플랜 반려" 게임 오버.
- 비행선 체력(장비 상태) 0 = 게임 오버. 암세포·암세포 탄환·바닥까지 내려온 세포(전이)가 깎음.
- 출력 드리프트: 시간이 지나면 Output 오차가 쌓임. 선량이 그만큼 커지거나 작아지고 조준이 흔들림.
- 인터락: 가끔 잠깐 발사가 멈춤.
- 숫자는 게임용 단순화 값. 실제 임상 기준이 아님.

## 무기
| 무기 | 동작 |
|---|---|
| X선 | 위로 직선 관통. 지나가는 모든 것(암, 세포, 장기)에 선량 |
| 전자선 | 5발 부채꼴, 사거리 짧음, 맞으면 멈춤 |
| 양성자 | 톡 찍은 지점까지 날아가 그 자리에서만 폭발. 가는 길엔 작은 선량, 뒤쪽은 0. 충전 필요 |

## 캐릭터
| 캐릭터 | 특기 (버튼, 재사용 대기) | 평소 장점 |
|---|---|---|
| 의사 | 윤곽 그리기: 6초간 숨은 미세 병변이 보이고 암 피해 1.3배 | 암 피해 +10% |
| 방사선사 | 호흡 게이팅: 암 움직임 멈춤 + 자동 조준 | 이동 빠름, 드리프트 흔들림 절반 |
| 의학물리사 | QA 보호막: 장기 피해 0, 출력 오차 0 | 드리프트 절반 속도, 인터락 덜 남 |

## 스테이지 (v1)
1. 폐암: 우폐 종양이 호흡으로 위아래 이동. OAR: 척수, 심장, 좌폐.
2. 전립선암: 직장이 바로 앞(빔 입사 쪽), 방광이 뒤. OAR: 직장, 방광, 양쪽 대퇴골두.
3. 뇌종양(보스): 돌아다니고, 안 맞으면 재증식, 페이즈마다 탄막. OAR: 뇌간, 시신경교차, 수정체.

각 스테이지에 숨은 미세 병변(선택 목표)이 있음. 결과 화면에 장기별 최대 선량과 등급.

## v1.3 추가 (2026-11-26)
- IMRT 무기: 빔 7줄. 줄마다 종양·장기 유무로 세기 결정 — 종양만 1.0, 종양+직렬 장기(factor ≥ 1) 0.25, 종양+병렬 장기 0.75, 장기만 0(닫힘), 빈 줄 0.4. 쏠 때마다 모든 장기에 약한 산란 선량.
- RapidArc 필살기: 게이지 25초 충전, 4초간 몸 둘레 타원 궤도를 돌며 종양 중심으로 계속 사격. 도는 동안 조작 불가·무적.
- 양성자: 자동 조준(종양의 현재 위치), 톡 하면 그 자리로. 충전 중 톡은 예약. 충전 1.6초.
- 버튼 줄 2줄: 윗줄 무기 5개, 아랫줄 특기 + RapidArc. 화면 비율 400x800.

## v1.4 변경 (2026-11-26)
- IMRT를 step & shoot으로 변경: 7개 고정 각도(G 180°부터 51.4° 간격), 이동 0.4초 → 세그먼트 3개 × 0.3초. 세그먼트 ① 종양 전체 ② 직렬 장기 왼쪽 ③ 직렬 장기 오른쪽 → 직렬 장기를 지나는 빔렛은 1/3만 조사. 빔렛 11줄(6 px 간격).
- MLC 시각화: 비행선 앞 11개 날개 + 화면 왼쪽 아래 BEV 창(좌우 날개 뱅크 14쌍, 종양 투영 원, 직렬 장기 띠).
- IMRT 동안 조작 불가·직접 피격 없음. 바닥까지 간 세포(전이) 피해는 3으로 줄여서 받음.
- 블루팬텀 물대포 삭제(치료와 무관). 대신 출력 오차 6% 초과 → DOSE 1 인터락 2.2초 → 물리팀 재보정(0%).
