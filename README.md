# DosiCare 암 퇴치 작전

리니악 비행선을 몰고 환자 몸속으로 들어가, 암에는 처방선량을 채우고 정상 장기는 지키는 방사선치료 슈팅 게임입니다.
폰 세로 화면용으로 만들었고, PC에서도 됩니다.

## 하는 법

`index.html` 파일 하나만 브라우저로 열면 됩니다. 설치할 것은 없습니다.

| 조작 | 폰 | PC |
|---|---|---|
| 이동 | 손가락으로 끌기 | 방향키 / WASD |
| 빔 | 자동 발사 | 자동 발사 |
| 무기 바꾸기 | 아래 윗줄 버튼 | 1–5 |
| 양성자 조준 | 자동 조준. 화면을 톡 하면 그 자리로 | 클릭 |
| 특기 | 아랫줄 왼쪽 버튼 | Space |
| RapidArc | 아랫줄 오른쪽 버튼 (게이지가 차면) | R |
| 일시정지 | 오른쪽 위 버튼 | P |

## 규칙

- 암의 체력은 처방선량(Gy)입니다. 다 채우면 사라집니다.
- 빔이 지나가는 길에 있는 정상 장기도 선량을 받습니다. 장기마다 한계가 있고, 넘으면 "플랜 반려"로 집니다.
- 시간이 지나면 출력(Output) 오차가 쌓입니다. 블루팬텀 물대포로 보정합니다.
- 화면의 Gy 숫자는 게임용으로 단순화한 값입니다. 실제 임상 기준이 아닙니다.

## 무기

| 무기 | 특징 |
|---|---|
| X선 | 위로 직선 관통. 지나가는 장기도 맞음 |
| 전자선 | 부채꼴 5발, 사거리 짧음 |
| 양성자 | 조준한 자리에서만 터짐(브래그 피크). 충전 1.6초 |
| IMRT | 빔 7줄. 직렬 장기 앞에서는 MLC가 거의 닫히고, 병렬 장기 앞에서는 조금 닫힘. 몸 전체에 약한 산란 선량 |
| 물대포 (블루팬텀) | 출력 오차 보정, 장비 회복 |
| RapidArc | 필살기. 4초 동안 환자 둘레를 한 바퀴 돌며 모든 방향에서 종양 조준 |

## 캐릭터

| 캐릭터 | 특기 |
|---|---|
| 의사 | 윤곽 그리기 — 숨은 미세 병변이 보이고 암 선량 1.3배 |
| 방사선사 | 호흡 게이팅 — 움직이는 암이 멈추고 빔이 따라감 |
| 의학물리사 | QA 보호막 — 정상 장기 선량 0, 출력 오차 0 |

## 스테이지

1. 폐암 — 숨 쉴 때마다 움직이는 종양
2. 전립선암 — 빔 바로 앞에 있는 직장
3. 교모세포종 — 돌아다니고 다시 자라는 보스

## 파일

- `index.html` — 게임 전체 (로고 이미지 포함)
- `assets/` — 로고와 비행선 마크 원본
- `docs/` — 설계 문서
